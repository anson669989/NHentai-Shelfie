# 任務 002：資料夾頁的資料夾切換改成下拉選單

> 目標版本：v0.1.1（與任務 001 一起發佈）　·　建立：2026-11-06
> 開始前先讀 `CLAUDE.md`；可在任務 001 完成後做，也可先做（兩者互不相依）。

## 1. 現況

`src/components/FoldersPage.vue` 頂部是一排橫向捲動的標籤（chip）：「全部」「未分類」＋自建資料夾＋「＋」，右側是排序下拉選單。長按資料夾標籤可改名、刪除、往前／往後移。

問題：資料夾一多就要左右滑找，看不到全部；長按管理功能使用者不容易發現。

## 2. 改成

頂部列改為兩個控制項並排：

```
[ 📁 待看  (12)        ▾ ]   [ 加入時間（新→舊）▾ ]
```

- **左：資料夾選擇器**（佔較寬空間）：按鈕外觀與新增頁的資料夾選擇器（`.select-like`）一致，顯示目前資料夾名稱與本數。
- **右：排序選單**：維持現狀。

點資料夾選擇器 → 由下方滑出的選單（沿用 `DialogHost.vue` 的 sheet 樣式），內容由上而下：

1. 「全部 (N)」
2. 「未分類 (N)」
3. 分隔線
4. 每個自建資料夾一列：`名稱 (本數)`，目前選中的那列標示勾號；每列右側一個「⋯」按鈕
5. 分隔線
6. 「＋ 新增資料夾」

行為：

- 點一列 → 切換到該資料夾並關閉選單，封面牆捲回頂部。
- 點「⋯」→ 開啟該資料夾的動作選單：改名、往上移、往下移、刪除（沿用現有 `folderMenu()` 的邏輯與確認對話框）。原本的「往前移／往後移」字串改為「往上移／往下移」。
- 「＋ 新增資料夾」→ 沿用現有 `newFolder()`，建立後自動切換到新資料夾。
- 「全部」「未分類」沒有「⋯」，不可改名、刪除、移動。
- 資料夾很多時，選單本身可捲動（最大高度約 70vh）。
- 選單開著時按 Android 返回鍵 → 關閉選單（DialogHost 已支援 `closeTopDialog()`）。

## 3. 實作提示

- 每個資料夾的本數：在 `library.js` 新增 `folderCounts()`，一次查詢回傳 `{ all, uncat, byFolder: { [id]: n } }`（`SELECT folder_id, COUNT(*) FROM book_folders GROUP BY folder_id`），取代目前只算「全部／未分類」的 `counts()`；介面只呼叫服務層，不直接碰 DB。
- `ui.js` 需要新的對話框類型（例如 `folderPicker`），或擴充 `actionSheet` 讓每列可帶次要按鈕；擇一即可，保持 DialogHost 單一出入口。
- 移除資料夾標籤列的 `v-longpress` 與橫向捲動樣式（`.folder-tabs`、`.chip` 若無其他地方使用就刪除）。
- 所有新字串補齊 zh-TW / en / ja；外部文字（資料夾名稱）一律純文字渲染。
- 新增頁的資料夾多選、長按封面的「加入資料夾…」不在本任務範圍，維持現狀。
